# RWH-OPTIMIZER — By. Mushthofa

Aplikasi HTML mandiri untuk simulasi pemanenan air hujan (*rainwater harvesting*), mencakup modul rumah tangga dan embung komunal.

## Publikasi menggunakan GitHub Pages

1. Masuk ke https://github.com, kemudian buat repository publik bernama `rwh-mushthofa` (nama lain juga boleh).
2. Di halaman repository, pilih **Add file → Upload files**.
3. Unggah **isi folder** ini langsung ke direktori utama (*root*) repository: `index.html`, `README.md`, dan `.nojekyll`. Jangan mengunggah file ZIP saja jika ingin GitHub Pages langsung menampilkan halaman.
4. Klik **Commit changes**.
5. Buka **Settings → Pages**.
6. Pada **Build and deployment**, pilih **Deploy from a branch**; **Branch: main**; **Folder: /(root)**, lalu **Save**.
7. Setelah GitHub Pages menyatakan berhasil diterbitkan, alamat publik biasanya: `https://NAMA-AKUN.github.io/rwh-mushthofa/`.

> Ganti `NAMA-AKUN` dengan nama akun GitHub Anda, dan sesuaikan `rwh-mushthofa` bila nama repository berbeda. Alamat tersebut bukan tautan aktif sampai publikasi GitHub Pages selesai.

## Menjalankan secara lokal

Klik dua kali `index.html` untuk membukanya dengan Chrome atau Edge. File ini menyimpan gambar/diagram secara internal sehingga tidak memerlukan folder gambar.

## Ruang lingkup

HTML adalah versi browser mandiri, bukan port identik seluruh komponen dan fitur Streamlit pada `rwh.py`. Perhitungan HTML perlu diverifikasi terhadap versi Python menggunakan data dan parameter yang sama sebelum dijadikan hasil penelitian final.

## Catatan publikasi

Repository publik dapat diakses orang lain, termasuk semua isi `index.html` dan gambar yang tertanam. Pastikan foto pribadi dan materi yang disertakan memang boleh dipublikasikan.
